The frame

Claude Code is the most capable AI development environment ever shipped. To make it the way your team actually builds — across machines, across teammates, across weeks of work — it needs two things that don't come in the box: long-term memory, and the ability to share what it learns.

Mem-Fusion adds both. The longer you use it, the sharper your Claude gets at your work, in your codebase, with your preferences. Everything runs on your machine; nothing leaves it without your say-so.

What's in the box

Three things, working together.

01

Long-term memory

Four Claude Code hooks watch your sessions and capture decisions, errors, and code patterns as you work. Vector search surfaces what's relevant the next time you ask. No taxonomy to design, no save button to remember.

02

Local by default

Qdrant and Ollama run on your machine. No cloud account, no telemetry, no SaaS lock-in. Your data is yours — the architecture enforces it, not a policy.

03

Sharing built in

When you're ready, memory flows across your other devices or your teammates. Two paths: a peer mesh with no server in the middle, or connectors that bridge into the productivity tools your team already uses.

Sharing

Two paths. Run neither, one, or both.

Path 1 — direct

Constellation today

A peer mesh that pools memory across your machines and teammates' machines directly. Each peer holds the full history; any peer can serve a catch-up. No orchestrator, no central service, no cloud provider in the middle.

Best when cloud tools aren't an option — corporate environments, fully private setups, or offline-first teams.

Path 2 — through your stack

Connectors v0.5, in design

Bridges into the productivity tools your team already uses. Slack ships as the bundled default; Google Drive, Microsoft Teams, Notion, and custom connectors plug into the same sharing API.

Best when your team already lives in Slack or another shared substrate and you want memory to flow through the channels that already exist.

How it installs

The installer is AI-native.

There's no bash installer to download and trust. You paste a markdown file into your Claude Code session and Claude runs the steps with your approval — out loud, one at a time. ~10 minutes, ~200 MB on disk.

01

Open Claude Code

In a terminal on your Mac. (macOS + Homebrew + Claude Code is the only prerequisite.)

02

Paste the install file

Copy the contents of INSTALL_MEM_FUSION.md and paste into the Claude window.

03

Approve the steps

Claude reads, explains, and runs each step. You approve. Smoke test passes. Done.
